# فاز ۱۴ — ماتریس تست Billing

| دسته | سناریو | معیار پذیرش |
|---|---|---|
| قیمت | ایجاد intent با مبلغ معتبر میزبان | مبلغ از `TrustedQuoteProvider`، نه HTTP |
| قیمت | تغییر قیمت Catalog بعد از ایجاد تلاش آماده و قبل از انقضا | همان قیمت تأییدشده تلاش جاری استفاده شود؛ تغییر خودکار ممنوع |
| قیمت | قیمت یا revision ارسالی کاربر با قیمت قفل‌شده مغایرت دارد | بدون تماس با پیشخوان رد شود |
| قیمت | Quote منقضی می‌شود | dispatch مسدود؛ refreshReady با کلید جدید و Quote جاری |
| قیمت | شکست قطعی بدون برداشت، سپس قیمت خدمت تغییر می‌کند | تلاش جدید با مبلغ جدید؛ سابقه تلاش اول تغییرناپذیر |
| قیمت | timeout / 5xx / pending | هیچ retry با کلید جدید تا استعلام قطعی |
| قیمت | replay همان retry idempotency key | همان تلاش جاری، بدون ایجاد رکورد جدید |
| امنیت | نمایندگی دیگر، ادمین بی‌مجوز، جعل رویداد | رد و عدم تغییر دیتابیس/تراکنش |
| استرداد | خدمت غیرقابل‌استرداد یا رویداد نامعتبر | هیچ Refund محلی/مرکزی |
| استرداد | رویداد مجاز خودکار با پرداخت موفق | Refund آماده، اجرا با مجوز، کل مبلغ موفق |
| استرداد | تغییر سیاست خدمت پس از پرداخت | تنها snapshot سیاست تلاش موفق ملاک |
| استرداد | نیازمند ادمین | پس از approve فقط ادمین واقعی دارای مجوز قابل اجرا |
| استرداد | مسیر دستی | manual_pending بدون تماس خودکار و بدون success جعلی |
| استرداد | timeout پس از اجرای مرکزی | unknown و lookup همان کلید، بدون refund دوم |
| استرداد | فرایند تکراری/رقابتی | حداکثر یک پرونده Refund برای پرداخت موفق |
| تاریخچه | تغییر قیمت retry و نتیجه استرداد | ثبت مستقل قیمت/نتیجه هر تلاش و وقایع استرداد بدون PII |

**محل اجرا:** ابتدا PHPUnit Core و تست‌های Billing در Sandbox. پیش از Production: آزمون رقابت روی RDBMS واقعی، Mock مرجع پرداخت/استرداد، و تأیید قرارداد رسمی پیشخوان. **وضعیت فعلی:** تست واقعی Laravel این بسته در محیط کاربر هنوز اجرا نشده است.
