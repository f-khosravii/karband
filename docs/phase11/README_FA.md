# INTL Platform — بسته بررسی معماری و آمادگی انتشار (فاز ۱۱)

تاریخ بررسی: ۲۰۲۶-۱۰-۰۲. مبنا: نه بسته ZIP تحویل‌شده در همین گفتگو و پچ‌های در دسترس؛ این بررسی به نسخه واقعی مخزن روی رایانه شما یا دیتابیس‌های عملیاتی دسترسی ندارد. فایل ZIP قدیمی NCR جزء این ممیزی پکیج‌ها نیست.

**وضعیت:** مناسب برای برنامه‌ریزی و نصب مرحله‌ای در Sandbox؛ **فاقد تأیید انتشار عملیاتی**. فاز هشتم Billing، فاز نهم Service Requests و فاز دهم Audit هنوز در Sandbox واقعی شما آزموده نشده‌اند.

محتوا:
- `ARCHITECTURE_REVIEW_FA.md`: یافته‌ها، اولویت‌ها، محدودیت‌ها و معیار توقف انتشار.
- `DEPENDENCY_MAP_FA.md`: نقشه وابستگی Composer و مرز ارتباطات در زمان اجرا.
- `STAGED_INSTALL_FA.md`: ترتیب نصب و مراحل برگشت امن برای زمانی که امکان نصب فراهم شد.
- `TEST_MATRIX_FA.md`: چک‌لیست تست‌های خودکار و تست‌های عملیاتی لازم.
- `RELEASE_DECISIONS_FA.md`: تصمیم‌های معماری و موارد خارج از محدوده.
- `PACKAGE_CHECKSUMS.sha256`: هش فایل‌های تحویلی برای تشخیص تغییر تصادفی؛ امضای اصالت نیست.
- `tools/verify-platform-release.php`: اعتبارسنجی ایستای بدون تغییر دیتابیس و بدون درخواست شبکه.

**این بسته را اکنون نصب نکنید.** فایل پچ فاز ۱۱ فقط اسناد جدید و ابزار بررسی را اضافه می‌کند و پکیج‌های قبلی را بازنویسی نمی‌کند. در آرشیو یک کپی آرشیوی از ZIPها و پچ‌های پیشین نیز قرار دارد؛ برای هر پکیج در آینده تنها یکی از ZIP یا Patch به کار رود. دو پچ `intl-dynamic-forms.RECONSTRUCTED.patch` و `intl-documents.RECONSTRUCTED.patch` از ZIPهای قبلی بازسازی شده‌اند و صرفاً برای نصب در مخزن تمیز مناسب‌اند؛ **در پروژه‌ای که آن فاز قبلاً نصب شده به هیچ عنوان دوباره اعمال نشوند**.

برای اجرای بررسی ایستای محلی بعد از افزودن ابزار فاز ۱۱:

```bash
php tools/verify-platform-release.php
# فقط بعد از افزودن تمامی پکیج‌های باقی‌مانده و آماده‌شدن محیط:
php tools/verify-platform-release.php --complete
```
