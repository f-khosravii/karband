# تصمیم‌های قطعی و فرض‌های ممنوع در انتشار INTL

۱. **INTL Platform Runtime مرکزی ندارد.** هر سازمان دولتی استقرار، دیتابیس، شبکه، نگهداری و سیاست مجوز خودش را دارد. پکیج مشترک، کد است و استقلال استقرار هر مایکروسرویس را حفظ می‌کند.

۲. **Government Admin:** هر مایکروسرویس فعلاً متعلق به یک سازمان دولتی است. نیازی به فیلتر چندسازمانی برای Government Admin همان سرویس نیست؛ انجام هر اقدام همچنان Permission لازم دارد.

۳. **Agency:** نمایندگی طرف حساب اصلی است و فقط به پرونده‌ها/خدمات مجاز خودش دسترسی دارد. امکان چند کارمند در آینده، ضرورت مدل‌سازی امروز برای آن نیست.

۴. **Platform Admin:** امتیاز نامحدود ضمنی ندارد؛ تمام اختیارات با Permission صریح تعیین می‌شوند.

۵. **ServiceRecipient:** مشتری نمایندگی، موجودیت تجاری مرتبط با درخواست است؛ کاربر مستقیم سیستم نیست. داده شخصی مشتری در DB محلی میزبان باقی می‌ماند.

۶. **Workflow:** تنها مرجع وضعیت درخواست؛ تعاریف مستقل و نسخه‌بندی‌شده به‌ازای هر خدمت؛ فقط اقدامات، تغییر وضعیت، درخواست اصلاح و توضیح هنگام اقدام. سامانه مکاتبات یا Assignment جداگانه ایجاد نشده است.

۷. **Service Catalog:** بدون دسته‌بندی/زیرگروه؛ کاتالوگ هر مایکروسرویس مستقل است.

۸. **Dynamic Forms:** رویکرد Hybrid؛ مدل فرم نسخه‌بندی‌شده و قواعد پیچیده از طریق کد ثبت‌شده. خود UI پنل هنوز ساخته نشده است.

۹. **Documents:** فضای ذخیره‌سازی خصوصی محلی، تعریف مدرک اجباری/اختیاری، نگهداری نسخه‌های جایگزین و Scanner/ReplacementPolicy میزبان. فایل واقعی در تراکنش DB توزیع‌شده قرار نمی‌گیرد؛ سیاست پاک‌سازی فایل‌های orphan باید جداگانه در میزبان تعیین شود.

۱۰. **Billing:** هیچ مایکروسرویسی موجودی یا کیف پول ندارد. فقط قصد پرداخت و نتیجه قطعی/نامشخص را مدیریت می‌کند؛ سامانه مرکزی پیشخوان تنها مجری مالی است. API واقعی آن هنوز تعریف/تأیید نشده است.

۱۱. **Audit:** بر پایه Spatie Activitylog، ثبت گزینشی رویدادهای امنیتی/مدیریتی، نه جایگزین Workflow History. لاگ در DB محلی است و به‌خودی‌خود WORM یا tamper-evident نیست.

۱۲. **Notifications:** فعلاً به تعویق افتاده؛ نه سرویس اعلان، نه کانال فرضی و نه Outbox سراسری را پیش‌شرط بسته‌ها قرار ندهید.

۱۳. **NCR:** هیچ‌یک از پچ‌ها مجوز Migration یا جایگزینی منطق موجود NCR نیستند؛ اتصال و تطبیق، پروژه آزمایشی مستقل خواهد داشت.
